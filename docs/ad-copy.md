# Ad copy — Hinglish

Paste into Ads Manager beside the video. Meta shows ~125 characters of primary
text before "…more", so the first line carries the message on its own.

Destination for every ad: the landing page, with UTMs (see `campaign-plan.md`).
CTA button: **Learn More** (it is a landing page, not a direct install).

Rules every line below already follows (`compliance-checklist.md`): no profit,
no win rate, no "safe"/"guaranteed", no exchange logo, no competitor named.
